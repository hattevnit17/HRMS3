Chọn các danh mục cần đưa vào file mẫu. Danh mục dưới đây là dữ liệu minh họa.
Hướng dẫn xuất nhập hồ sơ khám
  1. Chọn các danh mục khám và xét nghiệm cần nhập.
  2. Chọn Xuất File định dạng dữ liệu để tải mẫu CSV, có thể mở bằng Excel.
  3. Điền dữ liệu vào mẫu và giữ nguyên tên các cột.
  4. Nhập ngày khám, chọn file hồ sơ và nhấn Import Dữ liệu.

Bản HTML chỉ mô phỏng thao tác và kiểm tra file đã chọn, chưa đọc hoặc ghi dữ liệu hồ sơ. Cho phép chọn file .xlsx, .xls, .csv, tối đa 20 MB. Khi tích hợp cần thống nhất cấu trúc Excel và quy tắc kiểm tra dữ liệu với hệ thống HRMS3.
